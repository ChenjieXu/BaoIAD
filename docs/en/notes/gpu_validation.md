# Real-GPU release validation

This is the stable documentation entry for BaoIAD's independent real-GPU gate.
CPU and static checks do not validate CUDA. Until exact-commit real-device
evidence passes, the release state is **GPU not validated**.

[Read the maintained GPU validation contract](https://github.com/Baosight-xVue/BaoIAD/blob/master/docs/release/gpu_validation.md).
