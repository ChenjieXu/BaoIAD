Welcome to BaoIAD's documentation!
===================================

BaoIAD is a unified benchmarking framework for industrial anomaly detection (IAD),
built on MMEngine (OpenMMLab style). It integrates 50+ anomaly detection methods
under a single config-driven interface for fair comparison across multiple datasets.
