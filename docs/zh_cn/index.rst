BaoIAD 文档
===================================

BaoIAD 是一个基于 MMEngine（OpenMMLab 风格）构建的工业异常检测（IAD）统一基准测试框架。它在单一的配置驱动接口下集成了 50 多种异常检测方法，支持在多个数据集上进行公平比较。
