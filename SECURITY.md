# Security Policy

## Supported versions

BaoIAD does not currently publish a supported-version schedule or response-time
commitment. Use the latest released version and review its release notes for
security-related changes.

## Reporting a vulnerability

BaoIAD does not currently have a verified private vulnerability-reporting
channel. Do not disclose exploit details, credentials, private data, or
unpatched vulnerabilities in a public Issue or pull request, and do not upload
datasets, private checkpoints, secrets, or internal service details.

This file will be updated when an approved private reporting channel is
available. Until then, no private reporting mechanism is offered.
